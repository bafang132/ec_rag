# TikTok Shop东南亚运营要点

> 平台：TikTok Shop ｜ 市场：东南亚（印尼/泰国/越南/马来/菲律宾/新加坡） ｜ 类目：Listing与商品运营 ｜ 文档类型：实操教程

## 一、平台模式

| 模式 | 说明 | 适合卖家 |
|---|---|---|
| 跨境店 | 中国主体入驻，从国内/保税仓发货 | 有供应链的国内卖家 |
| 本土店 | 目标国主体入驻，本地发货 | 有海外仓/本地团队的卖家 |
| 全托管 | 供货给平台，平台负责运营与销售 | 工厂型/供应链型卖家 |
| 半托管 | 卖家负责运营，平台提供物流履约方案 | 有运营能力的卖家 |

## 二、流量逻辑：内容电商

TikTok Shop 是「内容 + 货架」双场域：

1. **短视频**：达人带货短视频是核心流量来源。完播率 > 互动率 > 转化率，前 3 秒决定生死。
2. **直播间**：东南亚用户直播购物习惯已养成，优质直播间可占店铺 60% 以上 GMV。
3. **商城（货架场）**：搜索 + 推荐流量，承接主动购物需求。
4. **达人分销（Affiliate）**：设置佣金（通常 10%-20%），达人 samples 寄样合作。

## 三、选品特点（东南亚）

- **价格带**：主流成交价 3-15 美元，客单价低、走量。
- **热门类目**：美妆个护、家居日用、3C 配件、女装、母婴、食品饮料（部分国家需资质）。
- **内容属性**：适合「演示型」商品（清洁神器、收纳、厨房小工具）与「视觉型」商品（美妆、饰品）。
- **宗教与文化**：印尼/马来以穆斯林为主，服装需注意 modesty（宽松、长袖选项）；斋月（Ramadan）是全年最大促销季。

## 四、达人合作（Creator Marketplace）

1. **筛选达人**：按类目、粉丝画像、历史 GMV、互动率筛选；粉丝量不是唯一指标，垂直小达人（1-10 万粉）性价比常更高。
2. **寄样（Sampling）**：通过平台 Samples 功能寄样，达人发布视频后按成交付佣金。
3. **建联话术**：明确产品卖点、目标人群、视频要求（脚本方向）、佣金与额外激励。
4. **内容沉淀**：优质达人视频可授权为店铺素材，二次投流放大。

## 五、直播运营要点

- **时长与频次**：本土店建议日播 4-6 小时；跨境店可周播 3-5 场测试。
- **人货场**：主播（本地化表达）、货盘（引流款 + 利润款 + 福利款）、场景（本土化布景）。
- **节奏**：每 5-10 分钟一次互动抽奖，保持在线人数；整点秒杀冲人气。
- **语言**：印尼语/泰语/越南语为佳，英语可作为补充。

## 六、平台活动

- **双日促**：99 大促、双 11、双 12、618（各站点略有差异）。
- **斋月大促（Ramadan）**：3-4 月，东南亚全年最大促销，提前 6-8 周备货。
- **超级品牌日**：品牌商家可报名，平台给流量扶持。

## 七、合规要点

- 各站点禁售清单不同（如印尼禁售部分美妆成分、电子烟全禁）。
- 部分类目需本地认证（如泰国的 FDA 编号、印尼的 BPOM）。
- 本土店需本地公司资质 + 本地银行卡收款。
