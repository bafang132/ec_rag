# 亚马逊FBA入仓与仓储规则

> 平台：亚马逊 ｜ 市场：北美/欧洲/日本 ｜ 类目：物流仓储 ｜ 文档类型：规则解读

## 一、FBA 入仓流程

FBA（Fulfillment by Amazon）入仓分为四个步骤：创建发货计划 → 打印标签 → 选择头程物流 → 预约入仓。

1. **创建发货计划**：在卖家后台「库存 → 管理 FBA 货件」中创建发货计划，填写发货数量、包装类型（原厂包装/混装）。
2. 打印商品标签与货件标签：商品标签（FNSKU）贴在每件商品上，货件标签贴在箱外。
3. **头程物流**：选择快递（空运，3-7 天）、空加派（8-15 天）或海运（快船 18-25 天、慢船 30-45 天）。
4. **预约入仓**：热门仓（如 FTW1、ONT8、LAX9）需提前通过承运商预约，旺季排队可能长达 2-4 周。

## 二、仓储容量限制（IPI 体系）

亚马逊用 **IPI（Inventory Performance Index，库存绩效指标）** 衡量卖家的库存管理水平：

- IPI 由四个维度构成：冗余库存百分比、FBA 售出率、无在售信息的库存比例、FBA 存货覆盖率。
- IPI ≥ 500 分：不受仓储容量限制；IPI < 500 分：将面临仓储容量限制，且可能被收取**库存仓储超量费**。
- 提升 IPI 的核心动作：清理滞销库存（降价/促销/移除）、提高售出率、修复无在售信息 listing。
- IPI 每周更新一次，通常季末（3/6/9/12 月）会刷新一次容量门槛。

## 三、FBA 费用构成

| 费用项 | 计费方式 | 说明 |
|---|---|---|
| 配送费 | 按件（尺寸分段 + 重量） | 标准件与大件分段计费，2024 年起改用尺寸等级制 |
| 月度仓储费 | 每立方英尺/月 | 1-9 月费率较低，10-12 月旺季上调约 2-3 倍 |
| 长期仓储费 | 每立方英尺/月 | 库龄 ≥ 365 天的库存收取，费率远高于月度仓储费 |
| 入库配置费 | 按件 | 未按分仓建议发货时收取 |
| 移除/弃置费 | 按件 | 弃置约 0.5-2 美元/件不等 |

## 四、滞销库存清理策略

1. **降价促销**：设置 20%-50% 折扣 + Coupon，快速回笼资金。
2. **站外 Deal**：通过 Slickdeals、Dealnews 等站外渠道清货。
3. **批量移除**：长期仓储费临近时（库龄 330 天左右）评估移除成本 vs 继续仓储成本。
4. **线下渠道**：对接线下折扣店或清算商（通常回收货值的 5%-15%）。

## 五、旺季入仓注意事项

- Prime Day、黑五、网一前的入仓截止期通常提前 4-6 周，错过将无法及时入仓。
- 旺季仓储费上调期间，备货计划需重新测算利润空间。
- 建议分批发货，避免集中到港后遭遇塞港与爆仓。
