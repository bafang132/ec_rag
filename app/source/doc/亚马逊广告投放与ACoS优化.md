# 亚马逊广告投放与ACoS优化

> 平台：亚马逊 ｜ 市场：北美/欧洲/日本 ｜ 类目：广告与推广 ｜ 文档类型：实操教程

## 一、亚马逊广告类型

| 广告类型 | 展示位置 | 适用场景 |
|---|---|---|
| SP 商品推广 | 搜索结果页、商品详情页 | 主力广告，按点击付费（CPC） |
| SB 品牌推广 | 搜索结果顶部/中部 | 品牌曝光，带动品牌旗舰店流量 |
| SD 展示型推广 | 站内外的关联位置 | 再营销，收割浏览未购用户 |
| SBV 品牌视频 | 搜索结果中 | 高转化素材测试 |

## 二、核心指标定义

- **CPC（单次点击成本）**：每次点击的花费，由竞价与竞争度决定。
- **CTR（点击率）**：点击/曝光，健康基准 ≥ 0.4%（SP）。
- **CVR（转化率）**：订单/点击，健康基准 ≥ 10%（视类目而定）。
- **ACoS（广告成本销售比）**：广告花费 / 广告销售额 × 100%，衡量广告效率的核心指标。
- **ROAS（广告支出回报率）**：广告销售额 / 广告花费 = 1 / ACoS。
- **TACoS（总广告成本销售比）**：广告花费 / 总销售额，衡量广告对整体业务的占比。

## 三、广告结构最佳实践

1. **一个广告活动一个目的**：测词、冲排名、稳排名、清库存分开建活动。
2. **自动广告挖词**：新品先开自动广告（紧密/宽泛/同类/关联四种匹配），2-4 周后跑出搜索词报告。
3. **手动广告收词**：把自动广告中转化好的词移到手动广告（精准/词组/宽泛匹配分层）。
4. **否词**：每周把高曝光低转化/不相关的词加为否定，避免预算浪费。
5. **预算分层**：头部词活动占 50%-60% 预算，长尾词活动占 30%-40%，测试占 10%。

## 四、ACoS 优化路径

ACoS 过高时的排查顺序：

1. **看转化率**：CVR 低于类目均值 → 优化 listing（价格/评分/主图/五点），而非先降竞价。
2. **看点击率**：CTR 低 → 主图与标题竞争力不足，或竞价位置太后。
3. **看竞价与位置**：对 ACOS 好的词提高竞价抢首页顶部；对 ACOS 差且无转化的词降价或暂停。
4. **看出单时间分布**：广告单集中在夜间时段（无效点击多）→ 用分时竞价工具调整。
5. **看关联流量**：详情页广告的 ACOS 通常低于搜索广告，可用 SD 再营销补量。

## 五、新品期广告策略

- 第 1-2 周：自动广告 + 低竞价测词，积累数据。
- 第 3-4 周：手动精准广告打核心词，配合 Coupon 提升转化。
- 第 2 个月：根据数据扩词，逐步提升竞价抢自然排名；自然排名稳定后，逐步降低广告依赖（TACoS 回落）。

## 六、大促期间广告调整

- Prime Day / 黑五前 2 周：预算提升 50%-100%，测试高效素材。
- 大促当天：实时监控 ACOS，对超支活动设预算上限。
- 大促后：复盘活动表现，保留高效词与人群，清退低效活动。
