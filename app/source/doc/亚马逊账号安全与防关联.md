# 亚马逊账号安全与防关联

> 平台：亚马逊 ｜ 市场：全球 ｜ 类目：账号与合规 ｜ 文档类型：规则解读

## 一、账号关联（Account Linking）

### 定义
亚马逊通过技术手段识别同一卖家操作多个账户的行为。一旦判定关联，**所有关联账户可能同时被停用**。

### 常见关联因素
1. **硬件与网络**：同一 IP、同一设备、同一浏览器指纹（Canvas/WebGL/字体）、同一路由器 MAC 地址。
2. **注册信息**：同一法人、同一公司地址、同一收款账户、同一税号。
3. **运营痕迹**：同一手机号/邮箱、产品信息高度雷同、跨账号跟卖同一 ASIN。
4. **物流信息**：相同退货地址、相同发货地址。

### 防关联措施
- 一站一账号一环境：独立 VPS/云主机 + 独立网卡 + 独立浏览器配置文件。
- 注册资料完全隔离：不同法人、不同地址、不同收款账户。
- 运营行为隔离：不同上架时间节奏、不同产品结构，避免完全一致的运营模式。

## 二、账号二审（Second Review）

### 触发场景
新账号注册、修改关键信息（收款/信用卡/地址）、长期未登录后突然活跃。

### 审核材料
营业执照、法人身份证、银行对账单/信用卡账单（地址需与注册一致）、供应链发票（采购合同/增值税发票）。

### 视频验证（Video Verification）
部分二审要求法人出镜，回答审核官问题并展示证件原件。**切勿使用虚假资料，视频验证会核实人证一致性。**

## 三、KYC 审核（欧洲站）

欧洲站（英德法意西）强制 KYC：

1. 提交公司资料：营业执照、公司章程、受益人（UBO）信息。
2. 提交银行账户信息：对公账户或指定收款账户。
3. 审核周期通常 3-10 个工作日，材料不全会反复补交。

## 四、账户绩效指标（Account Health）

| 指标 | 红线 | 说明 |
|---|---|---|
| ODR 订单缺陷率 | < 1% | 差评 + A-to-Z + 拒付 |
| 迟发率 LSR | < 4% | 超过承诺发货时间发货 |
| 有效追踪率 VTR | > 95% | 有有效物流单号且可追踪 |
| 取消率 CR | < 2.5% | 卖家原因取消 |
| 退款率 | 视类目 | 部分类目有额外要求 |

绩效不达标会经历：警告 → 限制 FBA → 限制销售权限 → 停用。

## 五、封号申诉思路

1. **定位根因**：仔细阅读停用通知，确定违规类型（绩效/侵权/欺诈/关联）。
2. **制定 POA（行动计划）**：根因分析 → 已采取措施 → 预防机制（流程/人员/工具）。
3. **提交申诉**：通过卖家后台「账户状况 → 申诉」提交，一次提交完整材料。
4. **二次申诉**：被拒后补充新证据（如第三方检测报告、整改后的供应链合同）。

> ⚠️ 合规提醒：切勿购买已注册账号、使用虚假资料或第三方"解封黑科技"，此类行为一经发现将永久失去销售权限并可能承担法律责任。
