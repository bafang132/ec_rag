# 物流方式对比与头程方案

> 平台：多平台 ｜ 市场：全球 ｜ 类目：物流仓储 ｜ 文档类型：实操教程

## 一、头程物流方式对比

| 方式 | 时效 | 价格（参考） | 适用场景 |
|---|---|---|---|
| 国际快递（DHL/UPS/FedEx） | 3-7 天 | 40-80 元/kg | 补货急件、高客单价样品 |
| 空加派（空运 + 尾程快递） | 8-15 天 | 25-45 元/kg | 季节性补货、测试新品 |
| 海运快船（美森/以星） | 18-25 天 | 8-15 元/kg | 常规主力补货 |
| 海运慢船（普船） | 30-45 天 | 5-9 元/kg | 大批量低时效要求备货 |
| 铁路（中欧班列） | 25-35 天 | 10-18 元/kg | 欧洲线，性价比介于空海之间 |

> 价格为 2024-2025 年华东口岸到美国西岸的大致区间，随燃油与旺季波动。

## 二、FBA 头程方案选择

1. **快递直发**：适合新品测款（小批量、快验证）与紧急补货（断货在即）。
2. **空加派**：黑五前最后窗口期的补货手段；成本可控范围内抢时间。
3. **海运整柜/拼箱**：稳定款的主力补货方式，需提前 45-60 天规划。
4. **组合策略**：「海运为主 + 空运为辅」：按销量预测，60%-70% 货量走海运，30%-40% 走空运应对波动。

## 三、尾程配送

- **FBA 订单**：由亚马逊完成尾程配送，费用含在 FBA 配送费中。
- **FBM 自发货**：可选择邮政小包（便宜慢）、专线小包（性价比）、商业快递（快但贵）。
- **海外仓尾程**：海外仓对接当地 UPS/USPS/DPD，本地发货 2-5 天，物流体验接近本地电商。

## 四、清关与单证

- **必备单证**：商业发票（Commercial Invoice）、装箱单（Packing List）、提单（B/L）。
- **美国线**：需 ISF（10+2）申报；涉及 FDA 的产品（食品接触/化妆品/医疗）需提前注册。
- **欧洲线**：需 EORI 号；带电产品需 CE；纺织品需 CE + 成分标签。
- **日本线**：食品接触类需日本食品卫生法合规；带电产品需 PSE 认证。

## 五、常见物流风险与应对

| 风险 | 应对 |
|---|---|
| 旺季塞港/爆仓 | 提前 4-6 周发货；分仓发货；备选港口 |
| 海关查验扣货 | 单证如实申报；敏感货与普货分票；预留查验时间 |
| 货物丢失/破损 | 购买运输保险；选择可追踪渠道；保留发货照片 |
| 物流商跑路 | 选择有资质、经营年限长的货代；控制单批货值 |
| 船期延误 | 安全库存 + 2 周缓冲；启用空运应急通道 |

## 六、成本优化

1. **抛重比优化**：压缩包装体积，泡重货（体积大重量轻）重点优化，按体积重计费时空运成本可降 30%+。
2. **拼柜/集运**：小批量货物与其他卖家拼柜，摊薄成本。
3. **货代比价**：固定 2-3 家货代季度比价，旺季前锁价。
4. **海外仓前置**：爆款提前备至海外仓，尾程成本低于跨境直发，且时效体验更好。
