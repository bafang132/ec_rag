# 跨境电商术语表

> 平台：多平台 ｜ 市场：全球 ｜ 类目：多类目 ｜ 文档类型：术语百科

## 平台与账号

| 术语 | 全称/含义 |
|---|---|
| FBA | Fulfillment by Amazon，亚马逊物流，卖家发货至亚马逊仓由平台配送 |
| FBM | Fulfillment by Merchant，卖家自发货 |
| SFP | Seller Fulfilled Prime，卖家自发货但享受 Prime 时效 |
| ASIN | Amazon Standard Identification Number，亚马逊商品唯一识别码（10 位） |
| SKU | Stock Keeping Unit，卖家自定义的库存最小单位编码 |
| UPC/EAN | 商品条码，上架多数类目需提供 |
| KYC | Know Your Customer，卖家身份审核（欧洲站强制） |
| 二审 | Sale Verification，亚马逊对账号的额外审核（常含视频验证） |
| ODR | Order Defect Rate，订单缺陷率（差评+A-to-Z+拒付）< 1% |
| IPI | Inventory Performance Index，库存绩效指标，≥ 500 不受仓储限制 |

## Listing 与运营

| 术语 | 全称/含义 |
|---|---|
| Listing | 商品详情页（标题/图片/五点/A+/描述） |
| 五点 | Bullet Points，商品要点描述 |
| A+ 内容 | A+ Content，图文版详情页（品牌备案可用） |
| BSR | Best Seller Rank，类目畅销榜排名 |
| A9 | 亚马逊搜索排序算法 |
| Buy Box | 黄金购物车，详情页「加入购物车」按钮归属 |
| 变体 | Variation，同款商品的不同颜色/尺寸（父子体结构） |
| 跟卖 | Listing Hijacking，在他人 ASIN 下销售同款商品 |
| Vine | 亚马逊官方测评计划（最多 30 个评论） |
| 品牌备案 | Brand Registry，持 R 标在亚马逊备案获得保护与工具权益 |

## 广告与数据

| 术语 | 全称/含义 |
|---|---|
| SP | Sponsored Products，商品推广广告 |
| SB | Sponsored Brands，品牌推广广告 |
| SD | Sponsored Display，展示型推广广告 |
| CPC | Cost Per Click，单次点击成本 |
| CTR | Click Through Rate，点击率 |
| CVR | Conversion Rate，转化率 |
| ACoS | Advertising Cost of Sales，广告成本销售比 = 广告费/广告销售额 |
| ROAS | Return on Ad Spend，广告支出回报 = 1/ACoS |
| TACoS | Total ACoS，总广告成本销售比 = 广告费/总销售额 |
| ROI | Return on Investment，投资回报率 |

## 物流与仓储

| 术语 | 全称/含义 |
|---|---|
| 头程 | 从发货国到目的国的干线运输 |
| 尾程 | 目的国境内的末端配送 |
| 抛重/泡重 | 体积重，长×宽×高(cm)/6000（空运常用）或 /5000 |
| LTSF | Long-Term Storage Fee，长期仓储费（库龄 ≥ 365 天） |
| 入库配置费 | Inbound Placement Service Fee，未按分仓建议发货收取 |
| 海外仓 | 目的国本地仓库，支持本地发货 |
| EORI | Economic Operators Registration，欧盟进出口企业识别号 |

## 税务与支付

| 术语 | 全称/含义 |
|---|---|
| VAT | Value Added Tax，增值税 |
| IOR | Importer of Record，登记进口商 |
| OSS | One Stop Shop，欧盟一站式 VAT 申报 |
| C79 | 英国进口 VAT 缴纳证明（可抵扣） |
| MOQ | Minimum Order Quantity，最小起订量 |
| QC | Quality Control，产品质量检验 |

## 促销与营销

| 术语 | 全称/含义 |
|---|---|
| Deal | 限时促销活动（秒杀/7 天促销） |
| Lightning Deal | 秒杀（通常 12 小时） |
| Coupon | 优惠券（显示绿色徽标） |
| Prime 专享折扣 | Prime Exclusive Discount，会员专享价 |
| BOGO | Buy One Get One，买一赠一 |
| 黑五/网一 | Black Friday / Cyber Monday，11 月底两大促 |
