# 跨境电商选品与供应链要点

> 平台：多平台 ｜ 市场：全球 ｜ 类目：选品与供应链 ｜ 文档类型：实操教程

## 一、选品方法论

### 1. 数据驱动选品
- **需求侧指标**：核心词月搜索量、搜索趋势（Google Trends/卖家精灵）、类目 TOP100 平均评论数与评分。
- **竞争侧指标**：首页 Listing 质量（主图/评分/价格）、品牌集中度（Amazon Own Brand 占比）、广告 CPC 水平。
- **利润侧指标**：采购成本、头程运费、平台佣金、广告占比、退货率，倒推毛利率是否 ≥ 30%。

### 2. 选品红线（规避项）
- 需要复杂认证且无供应链支撑的类目（母婴/食品/医疗/带电产品先确保证书）。
- 季节性过强且无清货渠道的品（节日装饰）。
- 头部垄断型类目（TOP3 占 60% 以上份额）。
- 侵权高风险品（动漫 IP 周边、大牌仿款）。

### 3. 差异化路径
- **功能差异化**：组合销售（Bundle）、配件升级、场景细分（如"宠物专用"版）。
- **人群差异化**：针对细分人群（左撇子/露营/老年）做微创新。
- **视觉差异化**：包装升级、说明书本土化（多语言图文）。

## 二、供应商开发与管理

### 开发渠道
1. 产业带实地走访（深圳华强北、义乌、广州白云、东莞）。
2. B2B 平台（1688、环球资源）筛选 + 样品测试。
3. 行业展会（广交会、华交会、CES）。

### 供应商评估维度
- 产能与交期（是否支持小单快反）。
- 质量稳定性（索要过往 QC 报告）。
- 配合度（打样速度、定制能力、售后响应）。
- 资质（营业执照、产品认证、出口经验）。

### 合作条款要点
- **付款方式**：首付 30% + 验货后尾款 70%；拒绝 100% 预付。
- **MOQ（最小起订量）**：新品 300-500 件起，跑通后可谈阶梯价。
- **质检（QC）**：出货前第三方验货（约 100-200 美元/次），大货抽检不良率 > 2% 拒收。
- **备损**：合同约定 1%-3% 备损，覆盖运输与入库损耗。

## 三、利润核算公式

```
单件毛利 = 售价 - 采购成本 - 头程均摊 - 平台佣金(8%-15%) - FBA配送费 - 广告成本 - 退货损耗
毛利率   = 单件毛利 / 售价
```

健康基准：新品毛利率 ≥ 30%，成熟品 ≥ 25%；广告占比 ≤ 15%（成熟品）。

## 四、库存与补货模型

- **安全库存天数** = 采购周期 + 物流周期 + 3-7 天缓冲。
- **补货点** = 日均销量 × 安全库存天数；断货前 45 天（海运）启动补货。
- **滞销预警**：库龄 > 90 天且动销慢的 SKU 启动清货评估。
