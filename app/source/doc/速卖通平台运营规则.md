# 速卖通平台运营规则

> 平台：速卖通 ｜ 市场：全球（俄/西/法/巴为主） ｜ 类目：平台规则 ｜ 文档类型：平台政策

## 一、店铺类型与入驻

| 类型 | 特点 | 适合卖家 |
|---|---|---|
| 个人店 | 身份证即可入驻，部分类目受限 | 试水型卖家 |
| 企业店 | 需营业执照，可开全类目 | 正式运营卖家 |
| 品牌店 | 需商标授权或品牌备案 | 品牌商家 |

## 二、平台佣金与费用

- **类目佣金**：按成交金额收取 5%-8%（部分类目如手机 ≥ 8%）。
- **交易手续费**：每笔订单约 2%（2024 年起部分类目调整）。
- **推广费**：直通车（类似 CPC 广告）按点击计费，可设置日预算。
- **保证金**：部分类目需缴纳（通常 1 万-5 万元人民币），关店可退。

## 三、物流方案

1. **经济类**：中国邮政小包、ePacket（7-15 天，2kg 以下小件）。
2. **标准类**：AliExpress 无忧物流、云途专线（7-12 天，可追踪）。
3. **快速类**：DHL/UPS 商业快递（3-7 天，适合高客单价）。
4. **海外仓**：西班牙/法国/俄罗斯/巴西仓，本地发货 2-5 天妥投，提升转化但压资金。

## 四、纠纷与售后规则

- **买家保护期**：妥投后 15 天内（部分国家 23 天）可发起纠纷。
- **卖家响应时限**：买家发起纠纷后 3 天内必须响应，超时平台自动退款。
- **货不对板/未收到货**：平台介入后，卖家需提供有效物流追踪，无法举证将全额退款。
- **卖家责任取消订单**：将计入纠纷率，纠纷率高的店铺会被限制参加活动。

## 五、营销活动

- **店铺自主营销**：限时限量折扣、满立减、优惠券、粉丝专享价。
- **平台大促**：328 周年庆、618、828、双11、黑五（需报名，审核通过后展示专属标识）。
- **联盟营销**：设置佣金比例，通过联盟客引流，成交后付费。

## 六、违规与处罚

| 违规类型 | 处罚 |
|---|---|
| 售假/侵犯知识产权 | 商品下架、扣分、冻结账户，严重追究法律责任 |
| 虚假发货/运单号造假 | 扣分、关单、冻结保证金 |
| 引导线下交易 | 扣分、关店 |
| 类目错放 | 下架商品、扣分 |
| 成交不卖 | 扣分、关单 |

## 七、卖家体验分（Seller Performance）

由商品体验、物流体验、服务体验构成，直接影响搜索权重与活动资格。保持纠纷率 < 3%、好评率 ≥ 90%、及时发货率 ≥ 95% 为健康水平。
